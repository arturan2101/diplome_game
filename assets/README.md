# Assets

- `kenney_tiny_dungeon/tilemap_packed.png`: Kenney "Tiny Dungeon" 1.0 (16x16 tiles, 12x11 grid),
  https://kenney.nl/assets/tiny-dungeon, licence CC0 (see `kenney_tiny_dungeon/License.txt`).
- `placeholder/placeholder_tiles.png`: our own placeholder tiles for things the pack lacks
  (pit, spikes, coin, portal, bow and dash icons). Generated by `tools/make_placeholder_tiles.py`.
- `sprites/*.tres`: `AtlasTexture` resources, one per sprite. Scenes and data refer to these,
  so swapping the art means editing only these files (and the tile theme), not the code.
