# Обученный директор: обучение бандита

Данные: 10496 участков из 756 забегов исследующего директора (действие выбирается случайно и равновероятно), сиды 20000–20251; боты: слабый, средний, сильный. Каждое из 27 действий встречается от 328 до 441 раз.

Награда за участок: −1 гибель, −0,5 без урона, +1 HP на выходе 30–70 и время не больше 2·T_ref, иначе 0. Средняя награда в данных: 0,383; доля участков с +1: 0,515, с гибелью: 0,072.

Признаки контекста (8): bias, skill, hp, depth, last_result, hurt_by_skeleton, hurt_by_archer, hurt_by_beetle. Модель награды линейная по контексту для каждого действия; две схемы: независимая гребневая регрессия на каждое действие (как в LinUCB) и факторизованная (веса действия = веса его типа + уровня бюджета + врага). Схема и λ выбраны по оценке ценности политики на отложенных сидах.

DR (doubly robust): предсказание модели награды для выбранного политикой действия плюс поправка по настоящей награде там, где случайный выбор совпал с выбором политики. Вероятность каждого действия при сборе данных известна точно (1/27), поэтому оценка несмещённая; IPS — только поправочная часть, она тоже несмещённая, но шумнее (совпадает лишь каждый 27-й участок). Окончательная проверка — прогоны обученного директора на тестовых сидах.
